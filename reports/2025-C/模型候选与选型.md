# 2025 年研赛 C 题模型候选与选型

本文件是建模阶段的候选方案，不代表最终模型。先跑最小基线，再依据数据检查结果决定是否使用复杂模型。

## 问题 1：像素级裂隙分割

### 基线

- 灰度/颜色阈值 + 形态学去噪 + 连通域筛选，作为可解释基线。
- 评价：Precision、Recall、F1、IoU、误检/漏检可视化。

### 主候选

- U-Net 或轻量 U-Net：适合像素级二分类，数据量有限时可通过翻转、裁剪、亮度扰动增强。
- 若附件标注足够，比较带注意力或 ResNet 编码器的 U-Net；复杂模型必须证明相对基线的提升。

### 选择理由与约束

- 题目要求同尺寸二值图，分割模型输出与提交格式天然一致。
- 训练/验证按图像或钻孔分组切分，不能把同一图像裁剪块随机分到训练和验证造成泄漏。
- 类别不平衡时使用加权交叉熵、Dice 或 Focal 类损失，并报告阈值选择。

## 问题 2：正弦裂隙参数

推荐使用“连通域/DBSCAN 聚类 + 鲁棒正弦拟合”的单一处理链：

1. 二值图连通域提取，按面积、长宽比和连续性过滤伪影。
2. DBSCAN 或基于邻接关系的聚类，分离不同裂隙。
3. 用 FFT/网格搜索给 `P、β` 初值，再用非线性最小二乘拟合 `R、P、β、C`。
4. 用 RANSAC 或 Huber 损失降低离群像素影响。

约束：完整正弦裂隙的 `P` 应接近钻孔周长 94.25 mm；像素坐标必须根据 DPI/图像宽度转换为毫米后再拟合。

## 问题 3：复杂裂隙与 JRC

推荐“轮廓提取 + 两种采样策略 + JRC 对比”：

- 基线：等间距采样后按题给公式计算 `Z₂` 和 JRC。
- 改进：在曲率大、方向变化明显的位置加密采样，在平直段稀疏采样。
- 对比：改变采样点数 `N`，报告 JRC 的均值、标准差和相对变化。
- 面积分析：将裂隙面积作为分组或协变量，区分“真实粗糙度变化”和“轮廓长度/面积带来的采样偏差”。

## 问题 4：连通概率与钻孔补充

推荐“几何候选匹配 + 概率评分 + 不确定性驱动选点”：

- 几何候选：将每个钻孔的裂隙参数转换到统一三维坐标系，按空间距离、倾向、深度和 JRC 构造候选边。
- 概率评分：用距离、方向差、参数差和图像置信度构成可解释的 logistic/加权概率模型；权重必须通过数据或敏感性分析说明。
- 三维网络：节点是裂隙片段，边权是连通概率，输出阈值前后的网络和三维图。
- 补充钻孔：以最大化不确定性下降或覆盖收益/成本比为目标，先生成可行位置，再用贪心或整数规划选 3 个点。

## 失败替代

- 分割训练不稳定：回退到阈值/边缘/形态学基线并加强人工抽样检查。
- DBSCAN 对密度敏感：比较连通域规则和层次聚类，不直接声称簇数正确。
- 概率缺少标定数据：报告为相对连通评分或情景概率，并明确需要现场验证，不能包装成实测概率。
