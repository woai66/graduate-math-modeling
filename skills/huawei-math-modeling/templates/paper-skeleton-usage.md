# 论文骨架使用说明

`paper-skeleton.docx` 是可直接填写的研赛论文骨架。

**封面与摘要页直接沿用官方附件3 模板本身**（官方 logo、报名表格、华文新魏/隶书标题、页边距、页码起始），不是重新绘制的仿版；正文部分由脚本按附件2 的格式要求与优秀论文范式注入。这样做是为了让开头与官方发布完全一致。

已用 Microsoft Word 实际打开并导出 PDF 验证：5 页，封面页码 0、摘要页 1、正文从第 3 页（页码 2）开始，无空白页，宋体/黑体/华文新魏/隶书均正确显示。

## 封面（第 1 页，页码 0）

按官方模板保留：

- 四枚官方 logo（CPIPC、中国研究生数学建模竞赛、HUAWEI、承办高校）
- 三行赛事名称：中国研究生创新实践系列大赛（华文新魏 18 pt）、“华为杯”第二十三届中国研究生 / 数学建模竞赛（华文新魏 22 pt）
- 报名表格：学校、参赛队号、队员姓名 1/2/3（下划线式，直接填写）

**身份信息规则**：封面按官方模板填写学校、参赛队号、队员姓名；**正文及其后各页不得出现任何可能显示答题人身份的信息**（含姓名、学校、队号、图片水印、文档属性）。

## 摘要页（第 2 页，页码 1）

沿用官方模板版式：三行赛事名称 + “题 目：”（隶书 18 pt 标签 + 题目黑体三号）+ “摘 要：” + “关键词：”。中间插入灰色填写提示，写清建模思路、主要方法、模型、结果与结论、创新点，一般不超过两页，无需英文。

## 正文（第 3 页起）

| 样式 | 字体 | 字号 | 依据 |
| --- | --- | --- | --- |
| 一级标题 | 黑体，居中 | 四号 14 pt | 附件2 强制 |
| 二级标题 | 黑体，左对齐 | 小四 12 pt | 官方未规定，建议值 |
| 正文 | 宋体，两端对齐，首行缩进 2 字符 | 小四 12 pt | 附件2 强制 |
| 西文与数字 | Times New Roman | 随正文 | 中文学术惯例 |
| 图题表题 | 宋体，居中 | 五号 10.5 pt | — |
| 参考文献条目 | 宋体，悬挂缩进 | 五号 10.5 pt | 附件2 格式 |
| 表格文字 | 宋体 | 小四 12 pt | — |
| 代码 | Consolas | 五号 10.5 pt | — |
| 提示 | 宋体，灰色 | 五号 10.5 pt | 定稿前删除 |

章节结构：1 问题重述 → 2 问题分析与技术路线 → 3 模型假设与符号说明 → 4 数据来源与预处理 → 逐个问题「问题分析 / 数据与特征 / 模型建立 / 参数估计与求解算法 / 结果与分析 / 验证与敏感性分析 / 小结」→ 模型评价与推广（优点 / 不足 / 改进）→ 参考文献 → 附录（程序代码索引 / 复现环境 / 人工智能工具使用说明）。

## 重新生成

脚本以官方模板为底稿，需要指向你本机的附件3 模板：

```powershell
uv run python "skills/huawei-math-modeling/scripts/build_paper_skeleton.py" `
  "输出路径/论文骨架.docx" `
  --template "F:/goodstudy/研0/竞赛/数模/附件3：“华为杯”第二十三届中国研究生数学建模竞赛论文模板.docx" `
  --questions 4 `
  --title "你的论文题目"
```

`--questions` 取 1—5，对应题面的实际问题数量。`--title` 不填时保留模板的题目下划线，供手工填写。

也可以设置环境变量 `MATHMODEL_TEMPLATE` 指向模板文件，之后省略 `--template`。

## 定稿前必做

1. 搜索 `【`，删除全部灰色“提示”文字。
2. 逐个检查一级标题编号连续、图表编号与正文引用一致。
3. 跑格式检查：

```powershell
uv run python "skills/huawei-math-modeling/scripts/verify_docx_format.py" "你的论文.docx"
```

4. 用 Word 导出 PDF 后逐页目视检查分页、图表位置、页码与公式显示。
5. 公式用 Word 内置公式编辑器输入，不要贴截图。

## 已知限制

- 页码从 0 开始（封面 0、摘要页 1）是官方模板本身的行为，与附件2“从 1 开始连续编号”表面不一致。骨架保留模板行为；若开赛公告明确要求封面不显示页码，再单独调整。
- 承办高校 logo 来自官方模板，若当届模板更换，重新生成即可自动跟随。
- 封面标题使用华文新魏、摘要标签使用隶书，均为官方模板字体。换机器若缺字体，Word 会替换为相近字体，需目视确认。
- 二级标题小四黑体是建议值，官方只规定一级标题；若要更醒目可放大，但需全文统一。
