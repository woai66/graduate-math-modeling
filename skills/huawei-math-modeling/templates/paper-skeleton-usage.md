# 论文骨架使用说明

`paper-skeleton.docx` 是按“华为杯”第二十三届（2026）《论文格式规范》和优秀论文范式做好的可填写骨架。打开就能写，样式已经锁定，不需要自己调字号。

## 已锁定的格式

| 项目 | 值 | 对应官方要求 |
| --- | --- | --- |
| 纸张 / 页边距 | A4；上 30.0、下 17.5、左右 22.5 mm | 附件3 模板实测值 |
| 页眉 / 页脚距 | 15.0 / 17.5 mm | 同上 |
| 题目 | 黑体 三号 16 pt 居中 | 附件2 强制 |
| 一级标题 | 黑体 四号 14 pt 居中 | 附件2 强制 |
| 正文 | 宋体 小四 12 pt，单倍行距，首行缩进 2 字符 | 附件2 强制 |
| 西文与数字 | Times New Roman | 中文学术惯例 |
| 图题表题 | 宋体 五号 10.5 pt 居中 | 便于按章编号 |
| 参考文献条目 | 宋体 五号，悬挂缩进 | 附件2 格式 |
| 页码 | 封面不编号；摘要页起页脚居中，从 1 连续 | 附件2 强制 |

已用 Microsoft Word 实际打开并导出 PDF 验证：5 页，封面无页码、摘要页为第 1 页、正文第 2 页起，字体与字号实测符合上述值（microsoft_word_rendering 已通过）。

## 可直接使用的样式

在 Word 的样式库里选这些样式，不要手动改字号：

- `论文题目`：摘要页与封面上的题目
- `封面标题`：封面上的赛事名称
- `标题 1` / `标题 2` / `标题 3`：各级章节标题
- `正文`：所有正文段落
- `题注`：图题与表题
- `参考文献条目`：文献列表
- `代码`：附录代码
- `提示`：灰色小字的填写提示，**定稿前必须全部删除**

## 文档结构

封面（赛事名称 + 题目）→ 摘要页（题目、摘要、关键词，页码 1）→ 正文：

1. 问题重述
2. 问题分析与技术路线
3. 模型假设与符号说明
4. 数据来源与预处理
5. 问题一：模型建立与求解（问题分析 / 数据与特征 / 模型建立 / 参数估计与求解算法 / 结果与分析 / 验证与敏感性分析 / 小结）
6. 问题二、三、四：同一闭环结构
7. 模型评价与推广（优点 / 不足 / 改进与推广）
8. 参考文献
9. 附录（程序代码索引 / 复现环境与运行说明 / 人工智能工具使用说明）

题面问题数量不是 4 个时，删掉多余的问题章节，或按下面的命令重新生成。

## 重新生成

```powershell
uv run python "skills/huawei-math-modeling/scripts/build_paper_skeleton.py" `
  "你的输出路径/论文骨架.docx" --questions 5 --title "你的论文题目"
```

`--questions` 取值 1—5，对应题面的实际问题数量。

## 定稿前必做

1. 搜索 `【`，删除全部灰色提示文字。
2. 跑一次格式检查，确认没有被手动格式覆盖：

```powershell
uv run python "skills/huawei-math-modeling/scripts/verify_docx_format.py" "你的论文.docx"
```

3. 用 Word 的“插入题注”和“交叉引用”管理图、表、公式编号，不要手工编号。
4. 公式用 Word 内置公式编辑器输入，不要贴截图。
5. 导出 PDF 后逐页目视检查分页、图表位置与页码。

## 与官方模板的差异（有意为之）

- **封面不含“学校 / 参赛队号 / 队员姓名”字段**：附件3 模板保留了这张表，但附件2 明确禁止任何可能显示答题人身份的标志，两者冲突。骨架按附件2 处理。开赛公告若另有要求，再补上队号。
- **封面标题用黑体而非华文新魏**：模板的装饰字体依赖本机字体，换机器容易回退；正式要求只对题目和正文有规定。
- **一级标题编号用阿拉伯数字**（`1`、`1.1`）：官方未规定编号形式，全文统一即可。

## 已知限制

- 页脚位置由 `footer_distance` 近似匹配 Word 模板，与官方模板可能有毫米级差异，建议第一次使用时与官方模板并排比对一次。
- 骨架不预置图表数学公式，需要按队伍内容插入；公式的可编辑性无法由脚本检查，须在 Word 里点一下确认。
- `标题 2` / `标题 3`（小四黑体）是建议值，官方只规定了一级标题；若队伍想让二级标题与正文区分更明显，可自行放大，但要在项目内统一。
