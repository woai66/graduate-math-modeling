# 优秀论文范式画像

本文件来自本地优秀论文抽查，只用于学习论证密度、结构和表达方式；当届官方模板、页数、匿名和附件要求始终优先。

## 可以迁移的写作特征

- 每个子问题都形成闭环：题意与难点 → 数据与特征 → 基线 → 改进模型 → 参数/算法 → 结果 → 对比或消融 → 稳健性/敏感性 → 工程解释 → 失效边界 → 小结。
- 关键定义先给出自然语言解释，再给数学表达、变量单位和计算流程；自创指标必须提供反例、单调性/边界性质或合成实验。
- 图表不是装饰：正文先提出要回答的问题，再给图表，随后解释图表如何支持或限制结论。
- 多问之间保留接口：上一问输出如何进入下一问、单位是否变化、哪些不确定性被传递，都要在正文和结果索引中写清楚。
- 复杂模型必须有可解释基线或消融；“模型更复杂”不能自动等于“模型更好”。
- 结果段同时报告效果、误差、覆盖范围和失败样本，避免只展示最好的一组结果。

## 章节预算原则

论文没有统一的字数、页数、每问图表数量或参考文献数量门槛。章节长度由题面要求、模型复杂度、证据负担和官方限制共同决定：

1. 先列出每个结论所需的公式、表格、图和验证证据。
2. 删除重复解释、与结论无关的背景和仅为凑页数的图表。
3. 如果篇幅不足，优先保留定义、推导、关键结果、验证和局限；把可复现细节放入附录或附件。
4. 如果篇幅过长，优先压缩重复实验与代码叙述，不能删掉能改变结论的失败案例或验证。
5. 只有在当届官方规则允许时，才参考样本论文的正文页数范围；样本页数不构成通过条件。

## 论文质量自检

对每一个定量主张都能回答：

- 数值来自哪个运行版本、输入和参数？
- 它回答题面中的哪一个任务？
- 有什么基线、对照、独立验证或替代证据？
- 适用到哪些样本，哪些样本失败或未覆盖？
- 结论改变时，哪个假设或参数最敏感？

如果不能回答，主张降级为探索性观察或暂不写入摘要和结论。
