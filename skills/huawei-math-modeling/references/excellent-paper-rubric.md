# 优秀研赛论文质量审阅表

本表用于定位返工项，不把总分当作获奖预测、自动通过门槛或替代人工科学审阅。正式交付必须处理所有红线项；其余维度按题目和官方模板记录“充分/部分/缺失”。

| 维度 | 审阅问题 | 证据位置 |
| --- | --- | --- |
| 题目理解与问题拆解 | 背景、目标、输入输出、约束和子问题关系是否准确，是否覆盖题面要求 | 题目条款—结果—论文章节映射 |
| 假设与符号 | 假设是否有工程/数据依据，符号、单位、下标是否全文一致 | 假设表、符号表、数据字典、公式 |
| 数据与预处理 | 来源、规模、字段、缺失、异常、泄漏、划分和覆盖是否可复现 | 数据审计、运行日志、输入哈希 |
| 模型建立 | 目标、约束、概率/统计假设、推导和变量解释是否连贯 | 模型章节、推导核验、代码入口 |
| 参数与算法 | 参数来源、估计方法、初始化、停止条件、求解器和复杂度是否说明 | 配置、日志、结果索引 |
| 结果与验证 | 是否覆盖每个子问题，有基线/对照、独立验证、误差或不确定性 | 结果表、图、验证报告 |
| 敏感性与鲁棒性 | 关键参数、替代情景、重复运行或失败样本是否揭示稳定范围 | 敏感性结果、失败清单 |
| 创新与适用性 | 创新是否来自题目结构/数据/约束/验证，是否有消融或对比；边界是否诚实 | 创新论证、基线、消融、局限 |
| 图表与表达 | 图表是否有编号、单位、来源、图例和正文解释，版式是否服务于论证 | 图表清单、渲染页 |
| 引用与附录 | 引用是否真实可追溯，代码、数据字典、复现命令和附件是否齐全 | 引用表、附录、复现包 |

## 红线项

- 结果、精度、概率、排名或结论无法追溯到运行记录、原始数据或可靠文献。
- 用未标定的启发式分数冒充真实概率、准确率、工程量或最优解。
- 存在训练/测试泄漏、时序错误、约束未回代、量纲混乱或业务键覆盖。
- 子问题、题目要求的附件或官方格式缺失，且没有明确的排除依据。
- 参考文献、图表、公式、代码和正文数值互相矛盾。
- 论文含占位符、内部绝对路径、个人信息、账号广告或未经核验的 AI 生成结论。

审阅结论写成“已支持的主张 / 仍需证据的主张 / 阻塞项 / 建议动作”，不要只写一个分数。
