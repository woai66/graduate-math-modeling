# 数据分析与可视化

先复制原始数据的只读清单，记录文件哈希和读取方式。任何清洗都保存处理前后行数、字段数和规则，不能静默覆盖原始文件。

## 最小检查

1. 字段类型、单位、编码、时间范围和主键。
2. 缺失、重复、异常、极端值和不可能的物理范围。
3. 标签分布、类别不平衡、时间泄漏、空间重复和训练/测试划分。
4. 描述统计、分布、相关性、趋势和分组差异。

## 防错规则

- 时序数据按时间切分，不能随机打乱后再评价未来预测。
- 标准化器、缺失值填补器和特征选择器只在训练集拟合，再应用到验证/测试集。
- 目标变量和未来信息不得进入特征；任何派生特征写明时间窗口。
- 分类不只报告 Accuracy；至少补充 Precision、Recall、F1、混淆矩阵，必要时 ROC-AUC。
- 聚类先标准化，再用轮廓系数、Calinski–Harabasz 或稳定性比较簇数。
- 多目标优化先做量纲统一或归一化，再说明权重、Pareto 选择和约束回代。

## 图表

按 `figures/raw/`、`figures/process/`、`figures/result/` 保存源文件和导出图。每张图有编号、标题、单位、图例和数据来源；正文在图前提出问题，在图后解释图表对模型的作用。不要为凑数量复制同一信息。
