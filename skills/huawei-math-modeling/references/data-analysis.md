# 数据分析与可视化

先复制原始数据的只读清单，记录文件哈希和读取方式。任何清洗都保存处理前后行数、字段数和规则，不能静默覆盖原始文件。

## 最小检查

1. 字段类型、单位、编码、时间范围和主键。
2. 缺失、重复、异常、极端值和不可能的物理范围。
3. 标签分布、类别不平衡、时间泄漏、空间重复和训练/测试划分。
4. 描述统计、分布、相关性、趋势和分组差异。

## 防错规则

- 时序数据按时间切分，不能随机打乱后再评价未来预测。
- 标准化器、缺失值填补器和特征选择器只在训练集拟合，再应用到验证/测试集。
- 目标变量和未来信息不得进入特征；任何派生特征写明时间窗口。
- 分类不只报告 Accuracy；至少补充 Precision、Recall、F1、混淆矩阵，必要时 ROC-AUC。
- 聚类先标准化，再用轮廓系数、Calinski–Harabasz 或稳定性比较簇数。
- 多目标优化先做量纲统一或归一化，再说明权重、Pareto 选择和约束回代。

## 来源、版本与实现口径

- 先说明一行代表文本、配方、训练检查点、模型还是评测任务。实测、半合成、插值与估算结果保留来源标志；派生附件、子集和重复记录不能累加成独立样本量。
- 去重明确业务键、时间字段、时区、截止日、排序方向和并列规则；区分模型内部名称与目录名、最早与最新。实际代码、保存结果和数据说明不一致时，复核后如实报告，不能把“计划怎样处理”写成“实际已经处理”。
- 解析失败记录文件与错误，并写清整文件跳过、局部读取或修复的实际策略；不默默修补原始附件。缺失辅助字段不自动导致含有效核心变量的整行删除。
- 跨数据集评分固定训练/参考集上的变换再应用；分别归一化得到的相同数值不天然可比。跨问的同名质量分、损失和能力分须说明量纲、标定与误差，未标定时只能写接口假设。

## 验证对象与指标

- 按实际独立单位划分与重采样：同轨迹检查点、同模型家族及重叠时间窗口存在相关性。按行随机留出会泄漏；置信区间也不能把相关行当独立样本。
- 均值预测与分位数预测各用匹配的目标：均值看相应误差，分位数看 pinball loss、超越率及不确定性；不能仅凭均值 RMSE 否定或证明分位模型。区间很宽时应写证据不足，不凭点估计宣布校准成功或失败。
- 冻结外推与用目标数据校准后的迁移分开报告。看过留出结果后改模型，原留出已参与选择；称内部修订验证，若要声称独立验证须再有未使用的数据。
- 对照模型在相同样本和协议上独立拟合。把完整模型某项系数设零，不等于重新拟合不含该项的模型；删除历史项与只冻结未来增益也不相同。新区间须按新模型计算，不能借用旧模型区间。
