## 逐篇解剖

### B题：物理模型 + 单调校准 + 学习器的堆叠融合

方法链：逐子载波计算 SINR → 提取统计与结构特征 → EESM 物理模型拟合 α、β → Isotonic 校准等效 SINR 与速率的映射 → HGBR 学习残差与高阶交互 → 用最小化误差方差的闭式解求融合权重。

值得学：

- **物理量先于学习器**。先有 EESM 这个可解释的等效 SINR 映射，再用机器学习补它做不到的部分，而不是一上来就上模型。
- **假设直接支撑方法**。假设“无断层异常时等效 SINR 与 MCS 单调不降”，随后才使用保序回归；假设、数学工具、数据证据三者对得上。
- **融合权重有推导**。用最小化融合误差方差的投影解确定权重，并裁剪到 [0,1]，而不是拍一个 0.7/0.3。
- **防泄漏设计**。GroupKFold 按采集批次分组避免同源泄漏，交叉验证用 OOF 预测构造基线，避免用训练集预测喂给下一级模型。

可以质疑：

- 三问都只报全局 R²/RMSE，没有报告**误差在什么工况下集中**，也没有重复运行的波动或置信区间。
- 问题三 R²=0.702、Top-1=0.391，属于中等水平，但正文未系统讨论误差来源。
- 问题二用了 259 维特征训练随机森林，缺少特征重要性和消融，无法说明这些维度都是必要的。
- 全文验证都在同一批数据内做交叉验证，没有真正的外部验证集。
- 附录贴了约 20 页源码（占 76 页的约四分之一），正文实际论证篇幅被摊薄。

### 2025 C题：多方案对比 + 几何参数反演 + 实验设计思想

方法链：数据增强 → 灰度化/光照矫正/非局部均值/Gabor 方向滤波 → 三种识别方案横向对比 → 后处理 → GMM 聚类提取裂隙中心线 → 正弦模型参数反演（梯度下降-牛顿混合 vs 神经网络回归）→ JRC 粗糙度（等间距采样 vs 曲率-紧凑度自适应采样）→ 二阶导数改进 JRC → 三维平面重构 → 多因子加权连通性 → 信息熵识别高不确定性区 → 推荐补充钻孔。

值得学：

- **同一目标给三条技术路线并横向比较**，再说明选择理由，而不是只演示一条路。
- **把实验设计思想引入工程题**：用信息熵量化每个网格单元的不确定性，以“最大化信息增益”为准则推荐 3 个补充钻孔位置。这一步把“回答问题”提升为“指导下一步观测”，是全篇最有价值的创新点。
- **对指标的适用性提出改进**：指出等间距采样对轮廓复杂度不敏感，提出曲率-紧凑度加权自适应采样；指出一阶导数对线性趋势敏感，提出二阶导数改进模型。这类“旧指标 + 反例 + 改进”是干净可复现的创新写法。

需要警惕：

- **摘要自相矛盾**：摘要先说“方案对比后选择多特征融合的 Canny 边缘检测”，后面又写“经过比对发现 YOLOv8 效果更好”。同一篇论文对主模型给出两个结论，这在评阅中是硬伤。
- **裂隙条数口径不一致**：摘要一处写 1/6/3 条，问题二部分又写 5/1/3 条，没有说明口径差异。
- **用重武器打小目标**：正弦模型只有振幅、周期、相位、中心线四个参数，属于可解析或可稳定优化的低维问题，却用神经网络回归来反演。缺少“解析法/最小二乘在同一数据上失败”的证据。
- **把加权分数称为概率**：连通性用多因子加权综合，权重来源未标定，却直接命名为“连通概率”。命名超出了证据能支撑的范围。
- 无可信真值时报告“检测出 N 条裂隙”，没有给出误检、漏检或拒识的量化口径。

### 2025 F题：把抽象美学拆成可计算指标

方法链：路网图论抽象 → 几何复杂性与景观动态性 → 异景程度 → 多目标路径优化（改进遗传算法）→ 空间统计与形态学特征（位置、数量、面积比例、形状指数、离散度）→ 视域开合度量化与分级 → AHP-熵权综合评价 → 多核学习与深度度量学习求相似度 → 几何深度学习/跨模态注意力/时空图卷积 → 透视美学。

值得学：

- **开放题最关键的桥接动作**：把“趣味性”定义为“路径曲折度 + 沿途景观变化度”的综合函数，把“幻境感”定义为“空间多样性 + 开合节奏感”的综合体现。抽象概念先被写成一个能被计算的定义，才谈得上建模。
- **假设写得有分量**。四条核心假设（矢量图能充分表达美学特征；理想化观察者；美学特征可分解为弱相关微观指标的线性组合；园林为静态系统）明确圈定了全文的适用边界，让后续所有简化都有出处。
- **用几何量替代主观感受**。以视野扇形域量化“移步异景”，把审美体验转成可计算的空间关系。
- **连续指标分级**。开合度给出高度围合、中度围合、中度开阔、高度开阔的阈值区间，使数值结果可以被语义解释和工程使用。
- **报不确定性**。结果以“均值 ± 标准差”呈现，说明做过重复或扰动评估。
- **数据问题不回避**。明确列出 10 个园林的缺失值（合计约 6.2 万）和异常值（合计 290），并按缺失类型分别给出中位数填充、线性插值和 IDW 插值策略。

需要警惕：

- **假设与模型自相矛盾**：假设美学指标“可分解为弱相关微观指标的线性组合”，正文后半却使用多核学习、深度度量学习和跨模态注意力等强非线性模型。前后对同一问题给出两种互不兼容的立场。
- **数据支撑与模型规模不匹配**：输入只有二维矢量平面图，却引入时空图卷积等内容；这些模块是否被数据真正支撑，正文没有给出必要性论证。
- **模型介绍有教科书化倾向**：116 页中大段是通用方法原理，真正属于本任务的新推导和验证相对被稀释。
- 主观权重（AHP）与客观权重（熵权）的合成方式缺少标定过程的说明。

### 2024 C题（C24106130096）：诊断失败 → 改进 → 再验证，以及逐步消融的模型谱系

方法链：

- 问题一：阶跃数阈值分类（准确率 98.5%）→ 5 维时域特征 + SVM（100%）→ **模拟噪声环境测试抗噪性，精度下降约 26%** → 引入 Hilbert-Huang 变换与双谱时频域统计特征做多域融合 → 精度回升，且噪声下更稳。
- 问题二：NAdam 求解斯坦麦茨方程（相对误差 0.36）→ 对数法线性化 LSE（0.31）→ 乘 γT 或 e^{γT} 的温度修正（0.17 / 0.18）→ 深度自表示模型（0.13）。
- 问题四：分离模型与经验模型各自逐步改进，每加一个物理要素（对数化 → 温度 → 材料 → 波形）报一次误差，相对误差由 0.51 降到 0.02，并与深度特征嵌入编码器互相印证。
- 问题五：减式与除式两种带约束多目标模型，引入正则项 λ，用遗传算法和粒子群分别求解并对比。

值得学：

- **主动制造失败**：在 100% 准确率的“满分”结果上增加噪声场景，把精度打掉 26%，再据此改进特征。这是七篇里最有说服力的科研叙事结构——不是展示结果多好，而是找出它在什么条件下不成立。
- **逐步改进的消融链条**：每一个新版本只比上一版多一个要素，并给出对应误差。于是“创新点”不是一句口号，而是一条能逐项验证的改进轨迹。
- **同一方程用多种算法求解并对比**（另见 2024 C 另一篇使用最小二乘、模拟退火、粒子群求同一组参数），说明选型不是随手挑的。

需要警惕：

- **自创术语缺少定义**：“深度自表示”与最终模型命名较长，正文需要更严格的数学定义与消融，否则读者无法判断它比线性化改进多了什么。
- 误差只给单值，没有置信区间或重复运行波动。
- 105 页中包含大量附录源码，正文与附录的比重需要按当届规则重新权衡。

### 2025 E题（两篇）：跨域问题的源域/目标域纪律

方法链：源域样本筛选与数据增强 → 时域/频域/时频域/包络谱四类共 39 个候选特征 → 皮尔逊、斯皮尔曼、PCA、随机森林重要性、互信息、卡方六种方法筛选出 14 个重要特征 → SVM/RF/MLP 与 VGG/CNN 对比 → 域适应（决策边界对齐、MMD、CORAL、I-Softmax）→ 迁移过程的可解释性分析（迁移前/中/后）。

值得学：

- **源域与目标域从数据、特征到评价都分开叙述**，不混在一起。
- **特征筛选用多种准则交叉验证**，而不是只做一次相关性分析。
- **把可解释性当作一个独立问题**：迁移前（源域可迁移性）、迁移中（分布对齐过程）、迁移后（目标域结果解释）分别给证据。
- **把物理机理写进特征设计**：外圈、内圈、滚动体故障分别对应 BPFO、BPFI、BSF 特征频率，特征工程有物理依据。

需要警惕：

- **域内精度不能当跨域精度**。摘要中“MLP 在所有指标上超过 99.6%、ACC 达 99.66%”来自源域测试集；而目标域是“未知标签数据”，只能给出预测分布（如 4 个外圈、4 个内圈、5 个滚动体、3 个正常），**不能据此声称目标域准确率**。这是迁移学习题目中最常见的越界表述，我们要在写作时明确区分“域内性能”和“跨域性能”。
- 目标域仅十几个样本，任何“泛化性良好”的结论都需要限定适用范围。

## 跨论文共性：让论文站得住的动作

1. **概念到计算定义的桥接**：抽象词先写成可计算的量，再谈模型（F题最清楚）。
2. **物理/机理基线先行**，学习器只负责补基线做不到的部分（B题、两篇 2024 C 题）。
3. **主动制造失败并据此改进**：先证明方法在某个条件下不成立，再改（2024 C 篇最清楚）。
4. **逐步消融的改进谱系**：每加一个要素，报一次指标变化，创新点因此可追溯。
5. **多方案横向对比后择优**，而不是只演示一条路线。
6. **把优化或实验设计思想引入非优化题**：用信息增益、不确定性、灵敏度来决定下一步观测（2025 C 题的补孔设计）。
7. **连续指标分级**：给阈值区间，使数值结果能被语义解释和工程使用（F题开合度）。
8. **不确定性的显式表达**：均值 ± 标准差、信息熵、置信区间至少出现一种。
9. **总体技术路线图与正文逐问一致**，每问开头先讲与前后问的关系。

## 跨论文共性问题：需要辩证看待

这些是“看起来厉害、追问就塌”的模式，我们的规范要主动设防：

| 模式 | 表现 | 我们的处理 |
| --- | --- | --- |
| 模型堆砌 | 数据只是二维矢量图，却上时空图卷积与跨模态注意力 | 每个模型模块必须说明数据能提供什么信息、去掉它结果差多少 |
| 用重武器打小目标 | 4 参数正弦反演用神经网络回归 | 先证明解析法/经典优化在同一数据上失效，否则降级为对照 |
| 命名越界 | 多因子加权分数称为“连通概率” | 严格区分分数、指数、概率、置信度；未标定就改回“评分/指标” |
| 精度越界 | 源域精度当作跨域性能 | 明确标注评价集；无标签时只报预测分布与代理证据 |
| 假设与模型矛盾 | 假设线性可分解，正文用非线性深度模型 | 假设必须能覆盖全文所用方法；冲突时改假设或改模型 |
| 摘要与正文不一致 | 摘要一处选 A，一处选 B | 定稿前做“摘要—正文—结果”三方一致性核对 |
| 口径漂移 | 同一指标前后数量不同且不解释 | 所有跨章节数字纳入证据矩阵，同一量只允许一个口径 |
| 附录充篇幅 | 源码占全文四分之一以上 | 附录只放索引与关键片段；正文必须自足 |
| 误差不分解 | 只报全局 RMSE/R² | 至少按一个关键维度（工况/时段/站点/类别）分解误差 |

## 推陈出新：我们可以做得更好的方向

1. **误差的条件分解与失效地图**：除了全局指标，画出“在哪些条件下模型失效”，把失败样本作为正文的一等公民。
2. **假设的可检验化**：每条关键假设附一个可执行的检验或反例设计，而不是只写“合理假设”。
3. **模型的必要性证明**：为每个复杂模块准备“去掉它”的消融，让复杂度必须自证价值。
4. **指标命名的证据等级**：为自创指标标注它属于“评分/指数/概率/物理量”中的哪一类，以及达到该等级所需的标定证据。
5. **观测设计闭环**：像 2025 C 题那样，让模型输出不仅回答题目，还给出“下一步该测哪里、为什么”的可执行建议。
6. **跨问接口审计**：把上一问输出到下一问的输入写成显式契约（单位、分辨率、不确定度、匹配条件），并检查是否有量纲或口径漂移。
7. **反方审阅**：每问定稿前写一段“最强的反对意见及我们的回应”，把辩证思考留在过程记录里，把回应写进论文的局限性讨论。
8. **可比验证**：能拿到的话，用同题或相近方法的其他论文做定性对照，说明我们的假设、数据口径和结论差异，而不是比谁的数字更大。

## 使用方式

- 赛前：读“跨论文共性”和“推陈出新”两节，确定本次训练要刻意练习的 2—3 个动作。
- 选题后：找同题或同方法论文，按上面的四段结构（方法链、数据、亮点、可疑点）写一页解剖笔记，存到项目 `reports/`。
- 写作时：用“跨论文共性问题”做反向清单，逐条检查自己的稿子。
- 引用时：只引用可追溯的正式文献；这些资料论文的广告水印、数值和结论不得复制进我们的论文。
