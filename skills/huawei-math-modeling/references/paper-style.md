# 华为杯优秀论文写作规范

## 推荐结构

摘要与关键词 → 问题重述 → 问题分析与技术路线 → 模型假设与符号说明 → 数据初检与预处理 → 按问题逐节建模求解 → 模型评价与推广 → 参考文献 → 附录代码。

每个问题固定写：问题分析、数据处理、模型建立、变量/参数、算法或求解器、结果图表、对比/误差/敏感性验证、问题小结。

优秀论文级别还要求每问形成方法链：题意与难点 → 数据和特征 → 基线 → 改进模型 → 参数估计/求解 → 数值结果 → 对比或消融 → 敏感性/鲁棒性 → 工程解释 → 失效边界 → 小结。不得只罗列算法名称。

摘要中的每个定量结论必须在 `reports/evidence_matrix.csv` 中有 `claim_id`，并绑定结果文件、代码入口、运行参数和验证记录；没有证据的数字只能写成待验证计划。

## 格式约束

- 以当届官方模板为准；优秀论文只用于学习结构和表达。
- 公式单独居中并按章编号，如 (4-1)，公式后解释变量和单位。
- 符号表使用“符号—说明—单位”三列。
- 图表按章编号，如图 4-1、表 5-2；正文必须引用并解释图表。
- 摘要逐问写方法和定量结果，关键词为 3—8 个。
- 参考文献按正文出现顺序编号，网络资料、期刊和标准格式一致。
- 模型评价按问题写优点、局限、改进；不能只写统一的泛泛评价。
- 代码可按问题分块放附录或单独附件，正文保留关键接口和运行说明。

## 内容边界

不要为了达到固定页数或图数堆砌内容。优先保证每问覆盖、数据/公式/代码/图表/结论一致、验证可复现、引用可追溯。论文中不得复制资料中的 AI 账号广告、水印或未经核验的结论。
