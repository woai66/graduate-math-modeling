# 论文格式与排版规范

排版是参赛门槛，不是最后一步的美化。本文件以“华为杯”第二十三届（2026）官方文件为准，逐条写成可检查项。

## 0. 来源与优先级

| 来源 | 作用 |
| --- | --- |
| 附件2《论文格式规范》（2026-09-16） | **强制要求**，字体、字号、行距、页码、页眉、摘要、参考文献格式 |
| 附件3《论文模板》 | 版式结构：封面、摘要页、正文、页脚页码域 |
| 附件1《下载试题及上传论文操作手册》 | 提交格式：PDF、命名、识别码、附件限制 |
| 附件4《人工智能工具及输出使用规定》 | AI 使用与标注要求，见 `ai-compliance.md` |

当届文件更新时以最新版为准，并记录文件哈希与核验日期。本文件里的建议值（二级标题字号、页边距等）在官方未规定处给出，**官方模板优先于建议值**。

## 1. 官方硬性要求

| 项目 | 官方要求 | 怎么检查 |
| --- | --- | --- |
| 论文题目 | 三号黑体，居中 | 检查摘要页题目段落字体与字号 |
| 一级标题 | 四号黑体，居中 | 检查每一章标题 |
| 其他汉字 | 一律小四号宋体 | 抽样检查正文正文段 |
| 行距 | 单倍行距 | 检查段落格式 |
| 页码 | 从摘要页开始，位于每页页脚中部，阿拉伯数字从 1 连续编号 | 检查页码域与起始页 |
| 页眉 | 不能有页眉 | 检查每节页眉设置 |
| 身份标志 | 论文中不能有任何可能显示答题人身份的标志 | 检查正文、注释、图片、代码注释、文件名 |
| 摘要页 | 题目、摘要、关键词写在摘要页；摘要页下一页开始正文 | 检查分页与内容顺序 |
| 摘要内容 | 建模思路、主要方法、模型、结果与结论、创新点、关键词 | 逐项对照 |
| 摘要篇幅 | 一般不超过两页，无需译成英文 | 检查摘要页数 |
| 正文引用 | 用方括号标示编号，如 `[1][3]`；引用书籍必须指出页码 | 逐条核对 |
| 参考文献 | 按正文引用顺序列出，三种表述方式见第 7 节 | 检查顺序与格式 |
| 计算结果与源程序 | 如题目要求，需在规定时间内上传竞赛系统备查 | 对照题面与提交安排 |

## 2. 中文字号对照

Word 与 LaTeX 都需要换算，避免“看起来差不多”：

| 中文字号 | 磅值 | 常用场合 |
| --- | ---: | --- |
| 初号 | 42 pt | — |
| 小初 | 36 pt | — |
| 一号 | 26 pt | — |
| 小一 | 24 pt | — |
| 二号 | 22 pt | — |
| 小二 | 18 pt | 封面竞赛名称 |
| 三号 | 16 pt | **论文题目** |
| 小三 | 15 pt | 封面副标题 |
| 四号 | 14 pt | **一级标题** |
| 小四 | 12 pt | **正文、及其他汉字** |
| 五号 | 10.5 pt | 图表标题、表内文字、参考文献 |
| 小五 | 9 pt | 页脚页码、图内小注 |

## 3. 页面与版心

- 纸张 A4（210 × 297 mm）。
- 页边距官方未规定，采用模板默认值；模板缺失时用对称设置（上下 2.5 cm、左右 3.0 cm），并在项目记录中写明所用值。
- 页脚页码居中，用自动页码域而不是手工输入；起始页为摘要页（编号 1）。
- 不得设置页眉。
- 段落间距段前段后为 0，行距单倍；正文首行缩进 2 字符（若模板另有规定，以模板为准）。

## 4. 样式体系

**必须用样式排版，不要手工改字号。**手工格式会在增删段落、生成目录、交叉引用时失控，也无法被脚本检查。

| 样式名 | 中文字体 | 西文字体 | 字号 | 对齐 | 行距 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| 论文题目 | 黑体 | Times New Roman | 三号（16 pt） | 居中 | 单倍 | 摘要页顶部 |
| 一级标题 | 黑体 | Times New Roman | 四号（14 pt） | 居中 | 单倍 | 章标题 |
| 二级标题 | 黑体 | Times New Roman | 小四（12 pt） | 左对齐 | 单倍 | 官方未规定，建议值 |
| 三级标题 | 黑体 | Times New Roman | 小四（12 pt） | 左对齐 | 单倍 | 官方未规定，建议值 |
| 正文 | 宋体 | Times New Roman | 小四（12 pt） | 两端对齐 | 单倍 | 首行缩进 2 字符 |
| 摘要正文 | 宋体 | Times New Roman | 小四（12 pt） | 两端对齐 | 单倍 | — |
| 关键词 | 黑体标签 + 宋体内容 | Times New Roman | 小四（12 pt） | 左对齐 | 单倍 | “关键词：”用黑体 |
| 图题 | 宋体 | Times New Roman | 五号（10.5 pt） | 居中 | 单倍 | 置于图下 |
| 表题 | 宋体 | Times New Roman | 五号（10.5 pt） | 居中 | 单倍 | 置于表上 |
| 表内文字 | 宋体 | Times New Roman | 五号（10.5 pt） | 居中/左对齐 | 单倍 | 单位写在表头或表题 |
| 公式 | 宋体正文 + 数学字体 | Cambria Math / Latin Modern | 小四（12 pt） | 居中，编号右对齐 | 单倍 | 必须可编辑 |
| 参考文献 | 宋体 | Times New Roman | 五号（10.5 pt） | 悬挂缩进 | 单倍 | 按引用顺序 |
| 附录代码 | 宋体注释 + 等宽代码 | Consolas / Courier New | 五号（10.5 pt） | 左对齐 | 单倍 | 缩进用 Tab 或 4 空格 |
| 页脚页码 | 宋体 | Times New Roman | 小五（9 pt） | 居中 | 单倍 | 自动域 |

标题层级建议不超过三级。一级标题居中、二三级左对齐，编号统一为 `1`、`1.1`、`1.1.1`，全文一致，不混用“一、”“（一）”。

## 5. 数学公式

- **公式必须可编辑**：Word 用内置公式编辑器（OMML），LaTeX 用数学环境。截图公式、图片公式一律不合格，评委无法编辑，脚本也无法检查。
- 公式居中，编号右对齐，用制表位或无边框三列表格实现，不要用空格或连续回车对齐。
- 编号按章：`(3-1)`、`(3-2)`，跨章不重号。
- 排版惯例：变量与函数名斜体（$x$、$f$），常量、算子名、单位正体（$\mathrm{d}x$、$\mathrm{kg}$），向量与矩阵粗斜体（$\boldsymbol{x}$、$\mathbf{A}$），上下标中的文字说明用正体。
- 公式前用一句话引出，公式后解释每个符号的含义与单位，符号首次出现时与符号表一致。
- 长公式在关系符处换行，不强行压缩字号。

## 6. 图表

- 图题置于**图下**，表题置于**表上**，均居中、五号字，按章编号：`图 3-1`、`表 3-2`。
- 表格用三线表（顶线、表头线、底线），不使用竖线；表头跨页时重复。
- 每个图表都必须在正文被引用并解释：图前提出问题，图后解释结论，不能只放图不说话。
- 图片格式优先矢量（EMF、SVG、PDF）；位图分辨率不低于 300 dpi，线条图不低于 600 dpi。
- 图内文字在**论文最终版心**下不小于 8 pt。审查方式是按最终宽度缩放后再看，不是看原始像素。
- 配色采用低饱和科研配色（见 `diagram-workflow.md` 的 NPG 色板），避免高饱和渐变、阴影和荧光色。
- 数值图必须由真实数据与代码生成，保留数据、脚本和数据来源。

## 7. 参考文献

官方给出三种表述方式，照此执行：

```
书籍：[编号] 作者，书名，出版地：出版社，起止页码，出版年。
期刊：[编号] 作者，论文名，杂志名，卷期号：起止页码，出版年。
网上资源：[编号] 作者，资源标题，网址，访问时间（年月日）。
```

示例：

```
[1] 姜启源，数学模型，北京：高等教育出版社，12-45，2011。
[2] 王某某，李某，基于改进遗传算法的路径规划，系统工程理论与实践，42(3)：512-521，2022。
[3] 中国研究生数学建模竞赛组委会，竞赛章程，https://cpipc.acge.org.cn，2026年9月16日。
```

要点：

- 正文引用处用方括号，如 `[1][3]`；引用书籍时必须指出页码。
- 编号按正文首次出现的顺序，出现两次的只编一个号。
- 每条参考文献都必须被正文引用，正文引用的每条都必须在文献表中。
- 文献必须真实可查。不得编造作者、期刊、卷期或页码。
- 由 AI 输出且无法确认来源的模型或公式，按 `ai-compliance.md` 在参考文献中列出 AI 工具信息，并记住这类内容存在不被评阅认可的风险。无推导过程、无引用标识、无法确认来源的模型和公式一律不予认可。

## 8. LaTeX 路线

适合公式多、图表多、需要反复修改的论文。LaTeX 能把编号、引用、目录全部自动化，改章节不会移位。

基本链路：

```text
main.tex + refs.bib + figures/  →  xelatex → biber/bibtex → xelatex → xelatex  →  main.pdf
```

关键宏包与作用：

| 宏包 | 作用 |
| --- | --- |
| `ctex` | 中文支持与中文字号命令（`\zihao{3}` 等） |
| `geometry` | 页面与页边距 |
| `setspace` | 行距（`\singlespacing`） |
| `titlesec` / `ctexset` | 标题格式与居中 |
| `caption` | 图题表题格式、字号、间距 |
| `booktabs` | 三线表 |
| `graphicx` | 插图 |
| `amsmath`、`amssymb` | 公式环境 |
| `unicode-math` 或 `mathptmx` | 数学字体 |
| `gbt7714` 或 `natbib` | 参考文献样式 |
| `listings` 或 `minted` | 附录代码 |

可复用模板见 `../templates/latex/`。

常见坑：

- 编译必须用 **XeLaTeX**（或 LuaLaTeX），`pdflatex` 处理中文字体容易失败。
- 中文字体缺失会静默回退，导出后字体看起来“不对”，必须核对 PDF 的实际嵌入字体。
- 官方要求“小四宋体、单倍行距”，对应 `\zihao{-4}` 与 `\singlespacing`；不要用 `\linespread{1.5}` 去代替“单倍”。
- 浮动体可能跑到不合逻辑的页，定稿前逐图核对位置；必要时用 `[H]` 或调整段落。
- 表格过宽会溢出页面，需调整列宽或改用 `tabularx`。

## 9. Word 路线

模板本身就是 Word 文档，评委也按 Word 思路审阅，因此 Word 是默认路线。要点：

- 先定义样式，再写内容；不要边写边手动调字号。
- 公式用 Word 公式编辑器，插入后可用键盘输入 LaTeX 语法（Word 2021 及以上支持）。
- 图表用“插入题注”生成编号，正文用“交叉引用”引用，避免手工编号错位。
- 目录用自动目录域，改稿后按 F9 更新。
- 页脚插入页码域，并把摘要页设为第 1 页；检查“与上一节相同”的页眉设置已取消。
- 禁止用空格、空行、多个回车来对齐或分页；分页用分页符，段落间距用样式设置。

## 10. 两条路线的选择

| 情况 | 建议 |
| --- | --- |
| 公式多、推导长、图表编号复杂 | LaTeX 起草，最后核对能否满足官方字体要求 |
| 题目要求交 PDF 且需要与官方模板逐项一致 | Word 基于官方模板定稿 |
| 队伍不熟悉 LaTeX | 直接用官方模板 + 样式表，避免中途换工具 |
| 两种都做 | 以一份为唯一源稿，另一份只用于校验，避免两份不一致 |

无论走哪条，最终都是**按官方格式提交 PDF**。

## 11. 定稿验收清单

- [ ] 题目三号黑体居中；一级标题四号黑体居中；其余汉字小四号宋体；单倍行距
- [ ] 页码从摘要页起、页脚居中、连续编号；全文无页眉
- [ ] 全文无任何可能显示答题人身份的标志（含文件名、图片、代码注释、文档属性）
- [ ] 摘要页含题目、摘要、关键词；摘要含建模思路、主要方法、模型、结果与结论、创新点；不超过两页
- [ ] 每个公式可编辑，编号连续且按章组织
- [ ] 图题在图下、表题在表上；每个图表都在正文被引用并解释
- [ ] 参考文献按引用顺序、格式符合官方三种表述；每条都被正文引用；引用书籍标了页码
- [ ] 按 `ai-compliance.md` 完成 AI 使用标注
- [ ] 导出 PDF 后逐页目视检查：字体、分页、图表位置、公式显示、页码
- [ ] PDF 命名为 `题号+队伍编号.pdf`，生成 MD5 识别码后不再改动
- [ ] 有附件时按 `题号+队伍编号.rar` 命名，大小不超过 50 M

## 12. 自动检查

`scripts/verify_docx_format.py` 读取 DOCX 的实际样式与页面设置，检查字体、字号、行距、页码域、页眉与页面尺寸：

```powershell
python "<SKILL_ROOT>\\scripts\\verify_docx_format.py" "<PROJECT_ROOT>\\论文.docx"
```

它能报告段落与样式层面的偏差，不能判断公式是否可编辑、图表位置是否美观、分页是否合理。这些仍需导出 PDF 后人工逐页查看。
